## 修复 zhiwei-ai-brain 开发站 127.0.0.1 拒绝连接（request 5）
- 根因1：依赖损坏 —— npm optional-deps bug 导致 `@rolldown/binding-win32-x64-msvc`、`lightningcss-win32-x64-msvc`、`@swc/core-win32-x64-msvc` 缺失；且项目 `.npmrc` `engine-strict=true` 撞上 lock 里 react-router@8.4.0 新增 node>=22 engines 元数据，`npm i` 直接报错。解法：`npm i --engine-strict=false --legacy-peer-deps` 全量重装（node_modules+lock 删除重装；普通模式会撞 arborist "edgesOut" null 崩溃）。Windows 注意：逐个 `--no-save` 补装会互相顶删。

- 根因4：`npm run dev:local` 在 Windows 挂（spawn npx ENOENT，未 shell:true）；`npm run dev`（dev-run.js）可用。
- 最终启动方式（后台）：`export ZIMIO_ENV=dev SERVER_HOST=127.0.0.1 CLIENT_DEV_HOST=127.0.0.1; npm run dev:server & npm run dev:client`。dev 入口实际返回 200 的是 Nest `http://127.0.0.1:3000/app/app_17fdgjwy6dn/`（Vite 8080 的 base 路径返回 404，/@vite/client 200 正常，HMR 经 nest 转发）。

  - 会话过期且浏览器已关闭时清理临时目录；浏览器仍开则保留。
  - `oauth_begin` 不再需要 AppHandle；lib.rs 窗口事件只保留主窗口托盘逻辑。
